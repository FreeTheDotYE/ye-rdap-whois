# Security policy

Please report vulnerabilities, accidental disclosure, exposed credentials, or privacy-sensitive data through the repository host’s private vulnerability-reporting feature.

Do not place exploit details, secrets, personal-contact data, or unredacted sensitive evidence in a public issue. Non-sensitive data-quality corrections may use the normal contribution process.

Maintainers will assess the report, minimize further exposure, preserve necessary evidence, and coordinate a correction. No response-time guarantee is made.
